# NEEDFUL THINGS PARTNERS LLC

A curated contemporary lifestyle storefront for NEEDFUL THINGS PARTNERS LLC, built on the existing ecommerce engine.

Address: 1004 Annecy Pkwy, Nolensville, TN 37135  
Email: needfulthingspartnersllc@gmail.com

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
```

## Engine

This is a duplicate of the existing client-side ecommerce engine, restyled as a modern lifestyle retailer. Cart, wishlist, search, filters, sorting, product detail, demo login, and demo checkout are unchanged in behavior.

Coupon code `SAVE10` applies 10% on the cart page.
